# Tundra21 - Productivity App

Una aplicación completa de productividad personal construida con React y Vite.

## Características

### 1. **Tareas** 📋
- Organiza tus tareas por prioridad (Alta, Media, Baja)
- Categorías personalizables (Materias, Quehaceres, Reuniones, Actividades, Otro)
- Marcar tareas como completadas
- Eliminar tareas

### 2. **Calendario** 📅
- Vista mensual del calendario
- Agrega eventos por día
- Visualiza horarios de clase y actividades
- Navegación entre meses

### 3. **Rutinas** 🔄
- Rutinas flexible para cada día
- Actividades organizadas por hora
- Marcar actividades como completadas
- Duración y notas para cada actividad

### 4. **Finanzas** 💰
- Registro de ingresos y gastos
- Categorización de gastos
- Visualización de balance total
- Gráficas de gastos por categoría

### 5. **Pomodoro** ⏱️
- Temporizador Pomodoro (25min focus, 5min break)
- Sesiones personalizables
- Seguimiento de progreso diario
- Estadísticas de productividad

### 6. **Estudio** 📚
- Carga y gestiona documentos de estudio
- Resumen automático de documentos (IA)
- Flashcards para memorización
- Racha de días estudiados

## Instalación

```bash
# Clonar el repositorio
git clone https://github.com/gabo28yt-droid/tundra21-react-vite.git
cd tundra21-react-vite

# Instalar dependencias
npm install

# Ejecutar en modo desarrollo
npm run dev

# Build para producción
npm run build
```

## Tecnologías utilizadas

- **React 18** - Framework UI
- **Vite 4** - Build tool y development server
- **Lucide React** - Iconos
- **CSS3** - Estilos
